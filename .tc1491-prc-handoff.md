2. **Spool** (`shadow/spool.rs`, 1b-design §2, M4):
   - RAM WAL slot (cumulative, newest wins; one slot per DB) + on-disk
     snapshot spool at `{datadir}/sql-store-spool/{hash(key)}-pid.snap`.
   - Header `{key, revision, cid, sha256, len}`; temp+fsync+rename
     (no-clobber); dir fsync.
   - Reserve bytes through 1a's `DiskBudget` before writing (shed before copy).
   - Lock file refuses a second process on the same datadir.
   - Boot: delete leftover spool files when disabled.

3. **Uploader core** (`shadow/uploader.rs`, 1b-design §2–§3, contract 4.1):
   - Tick timer + size trigger; per-DB `in_flight` mutex; node-wide 8-cycle
     concurrency; FIFO by `first_dirty_at`.
   - Upload sequence: `store.put_if_absent` → `manifest.record_object` →
     `manifest.publish_cas`.
   - Lost-CAS handling (U2), orphan revive (U5), blocked-state on HEAD
     mismatch (U4).
   - Backoff: 1 s → 60 s doubling, ±20 % jitter (seeded RNG in tests).
   - Node-wide breaker opens at 5 consecutive failures, 30 s pause, half-open
     probe = one DB.
   - Shared PG semaphore (default 2, 1–4 permits) via `pg_concurrency`.
